V1 靛蓝卡片式
  • 左侧 232px 白色侧边栏 + 顶部栏
  • 四张 KPI 卡片，信息层级最清晰
  • 状态分段条 + 六项指标网格
  • 表格行悬停、描边小按钮
改动风险低 最接近现有结构 适合长期后台

三版对照

共同点：浅色底 / 白卡 / 细边框 / 状态胶囊
V1侧边栏导航，卡片化，稳重专业
V2横向导航，无侧栏，轻盈有编辑感
V3图标栏 + 左右分栏，层级与密度最高

选型建议

V1 直接替换现有侧边栏配色即可，改造量最小；V2 需要重排导航与统计区，视觉变化最大；V3 适合任务数量多、需要「先选批次再看详情」的场景，屏幕宽度要求更高。
